# TF-IDF Text Analysis

## Project Overview

This project demonstrates Term Frequency–Inverse Document Frequency (TF-IDF), a technique used to convert text documents into numerical features for text analysis.

## Objectives

- Understand Term Frequency (TF)
- Understand Inverse Document Frequency (IDF)
- Calculate TF-IDF scores
- Explore text feature extraction
- Analyze unstructured text data

## Technologies Used

- Python
- Jupyter Notebook
- TF-IDF
- Natural Language Processing

## Project File

- `TFIDF_Class_Activity_Solved.ipynb` – Solved practical notebook containing TF-IDF examples and classroom activities.

## Learning Outcomes

- Understanding text vectorization
- Working with numerical text features
- Exploring TF-IDF applications in Data Science
